The Minecraft server that parallelizes itself.

Pumpkin rewrote vanilla in Rust. Cinder is the next step: a Java Edition 26.2 server whose worldgen is a pure divide-and-conquer heightmap, scheduled across every CPU core and CUDA with no threads, locks, or kernels — and packet codecs the compiler proves cannot lie.

01 Instant process

One clang-built ELF. No HotSpot warmup, no 1.8 GB heap, no java -jar.

02 Parallel worldgen

A 16×16 heightmap is a balanced tree. Bend forks it over cores. ! sends the same tree to the GPU.

03 Proven packets

LAWS.bend pins VarInt encodings. The checker refuses a commit that frames 776 as anything but 88 06.

04 Affine, no GC

Values have one owner. match frees the node it opens. Idle RAM stays in the process, not a collector.

05 Binary TCP

Minecraft is not UTF-8. Cinder's foreign Bytes.recv / Bytes.send carry 0x00–0xFF intact.

06 MIT

Read it, fork it, host it. More permissive than Pumpkin's GPL-3.0.
